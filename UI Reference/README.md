# DealerSiteAudit Orange Brand Kit

## Approved identity
- Logo concept: Audit Frame + rising analytics bars + integrated growth mark
- Primary typeface: Manrope
- Wordmark color: Heritage Navy `#101C2C`
- Signature accent: Performance Orange `#F26419`
- Background: Warm Ivory `#F7F5F0`
- Body text: Graphite `#303945`

## Logo rule
Keep the entire **DealerSiteAudit** wordmark in Heritage Navy. Use Performance Orange only for the rising growth mark.

## Included
- SVG vector logos
- Transparent and background PNG exports up to 4200 px wide
- Light and dark versions
- Horizontal, stacked, and no-tagline variants
- Icon-only exports up to 2048 px
- Favicon PNG set and multi-size ICO
- Social media profile assets
- Open Graph and social share images
- Fully editable SVG master artwork
- High-resolution flattened orange source PNGs

## Typography
Use Manrope from Google Fonts. Font files are not included in this kit.

## Source files
The SVG files are the fully editable master artwork and should be used for vector editing. High-resolution flattened PNG source canvases are also included for compatibility.
